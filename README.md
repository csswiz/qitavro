# QITAVRO — Premium Editorial Online Bookstore

> **"A World Between the Covers."**

QITAVRO is a luxury independent bookstore and literary salon experience built with React, Tailwind CSS, Lucide Icons, and Three.js.

---

## ✦ Key Features

- **Luxury Brand & Design System**: Editorial typography (Cormorant Garamond, Playfair Display & Inter) with a palette of Warm Ivory (`#F6F0E8`), Burgundy (`#652E3C`), Deep Wine (`#421F2A`), and Muted Gold (`#B69A72`).
- **Interactive 3D Sanctuary Guardian**: Real-time Three.js 3D mythical dragon in the Hero section with scroll-linked vertical descent, dynamic flight banking, and warm editorial lighting.
- **Dynamic Catalogue & Filtering**: Fast client-side searching, sorting (popularity, price, ratings), genre filtering, and collection indexing.
- **Curated Thematic Shelves**: Dedicated Collections page for intentional browsing.
- **The Reading Room**: Magazine-style literary guides, essays, and reading lists.
- **Cart & Wishlist**: Persistent state powered by React Context API and LocalStorage.
- **Mobile Optimized**: Bottom navigation dock and fully responsive drawer interfaces.

---

## 🛠️ Tech Stack

- **Frontend**: React 18 (Vite)
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js & GLTFLoader
- **Icons**: Lucide React
- **Routing**: React Router DOM (v6)

---

## 🚀 Getting Started

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
npm run preview
```
